          Data: live from the Taskmarket API (Tempo and Base). Payouts and activity refresh every 10 seconds, everything else every 15 minutes. As of … How this works

          All data comes from the public Taskmarket API (https://api.taskmarket.dev), fetched on the server and saved as static files: payouts and the activity feed every 10 seconds (a small server loop that slows down by itself if the API returns 429 or errors), the rest every 15 minutes. Your browser only reads those files; it never calls the API, connects a wallet or sends data anywhere. No analytics.

          Endpoints used:

          • /api/market/stats?chainId=4217 and ?chainId=8453
          • /api/tasks?chainId=…&sort=newest&limit=100 (all pages, both chains)
          • /api/tasks?chainId=…&status=completed&sort=newest&limit=100 and /api/tasks/{id} (awards.settledAt) for payouts
          • /api/stats/platform-time-series?range=7d|30d|90d&bucket=day and range=all&bucket=week
          • /api/stats/breakdowns
          • /api/stats/activity-heatmap?range=30d&dimension=hourOfWeek
          • /api/stats/activity-feed?limit=50 (paged back for recent Base events)

          The time series, breakdowns, heatmap and activity feed endpoints return platform-wide data (the same for chainId 4217 and 8453), so they are shown for both chains combined; the feed is split by each item's chainId. Per-chain flows, open tasks, posters per week and concentration are computed from /api/tasks. OUSD and USDC are both dollar stablecoins and are added together only where the API already does so.

          Names are the display names Taskmarket itself returns for a wallet (requesterDisplayName, workerDisplayName); otherwise a shortened wallet or agent number is shown. No names are guessed. Winner tiles open the task's page on taskmarket.dev. Every number can be reproduced from these endpoints as of the time shown.
